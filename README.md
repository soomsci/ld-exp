# 빛의 세기와 거리 탐구 웹앱: 선생님용 설치 안내

## 파일
- `index.html`: 학생 화면 (설계 → 준비 → 측정 → 분석·보고서)
- `teacher.html`: 교사 대시보드 (제출 확인·채점·문항/배점 편집)
- `Code.gs`: 서버 (구글 시트를 DB로 사용, 그래프 이미지는 드라이브)
- `appsscript.json`, `.clasp.json`, `.claspignore`: clasp 배포 설정

## 설치 (10분)
1. 구글 드라이브에서 **새 구글 시트**를 만드세요 (예: "빛실험 제출함").
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 여세요.
3. `Code.gs` 내용을 편집기의 `Code.gs`에 붙여 넣으세요.
4. 왼쪽 **+ → HTML**을 눌러 파일 이름을 `index`로 하고, `index.html` 내용을 붙여 넣으세요.
5. **배포 → 새 배포 → 웹 앱**을 고르고 다음처럼 설정하세요.
   - 실행 계정: **나**
   - 액세스 권한: **[학교 도메인] 내 모든 사용자**
6. 권한 승인을 마치면 **웹 앱 URL**이 나와요. 이 주소를 학생들에게 공유하세요 (클래스룸 등).

코드를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영돼요.


## 교사 대시보드
- 주소: 학생 URL 뒤에 `?page=teacher` (배포한 교사 계정만 열 수 있음. 다른 교사는 `Code.gs`의 `TEACHERS`에 이메일 추가)
- **제출 현황·채점**: 반/상태 필터, 학생별 답변·그래프·모둠 데이터 확인, 문항별 점수·피드백 저장, "저장하고 다음 학생"
  - 변인 선택과 그래프(x축 = 1/d²)는 정답 여부가 ✓/✗로 표시돼요 (채점 참고용)
- **문항·배점 편집**: 발문, 배점, 필수 여부, 순서, 추가/삭제 → 저장하면 학생 화면에 반영
- **성적표 시트로 내보내기**: `성적` 탭에 반/번호/이름/문항별 점수/총점 정리

## 시트(DB) 구조
- `문항`: 문항 설정 (대시보드에서 편집, 처음엔 기본 10문항 20점)
- `모둠데이터`: 모둠 측정 데이터 (제출할 때마다 추가, 가장 최근 것을 사용)
- `제출`: 학생 1명당 1줄 (다시 제출하면 덮어쓰고 점수는 유지, 상태는 '재제출')
- 그래프 이미지는 내 드라이브의 `빛실험_그래프` 폴더에 저장돼요.

## ⚠️ 수업 전에 꼭 테스트할 것
1. **블루투스 연결:** 배포한 URL을 크롬북에서 열고 ② 실험 준비 → [센서 연결]을 눌러 보세요.
   - 목록에 "Light …" 센서가 뜨고, "현재 조도" 숫자가 움직이면 성공이에요.
   - "블루투스를 쓸 수 없어요"가 뜨거나 연결에 실패하면 → Apps Script 화면(iframe)이 블루투스를 막는 경우예요. 이때는 **수동 입력 모드**(스파크뷰 값을 보고 입력)로 수업하면 되고, 원하시면 GitHub Pages로 호스팅을 바꾸는 방법(계획서의 B안)으로 옮겨 드릴게요.
2. 센서의 조도값은 PASCO 공식 파이썬 라이브러리와 같은 방식으로 계산해요 (공장 보정값은 적용하지 않음). 그래서 스파크뷰 값과 몇 % 다를 수 있지만, **거리와의 비례 관계에는 영향이 없어요.**
3. 센서는 한 번에 기기 하나에만 연결돼요. 스파크뷰가 켜져 있으면 먼저 연결을 끊으세요.

## 광원 (네오픽셀)
- LED는 **1개만**, 흰색, 밝기 255(최대)로 고정하세요. 모든 모둠이 같은 코드를 쓰게 해 주세요.
- 추천 거리는 5~30cm, 5cm 간격이에요. 10cm와 20cm를 꼭 포함하세요 (Q1에서 "거리가 2배일 때"를 비교해요).

## 개발자용 점검
- 로컬에서 `index.html`을 열면 개발 모드로 동작해요. 제출 내용은 저장하지 않고 브라우저에만 남아요.
- 주소 뒤에 `?test`를 붙이면 회귀/R² 자가 점검이 콘솔에 출력돼요.
