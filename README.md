# 빛의 세기와 거리 탐구 웹앱

중학교 2학년의 거리별 빛의 세기 탐구를 위한 앱입니다. 학생은 모든 단계를 모둠활동으로 진행하며 **설계 → 준비 → 3회 측정 → 모둠 그래프 작성·분석** 순서로 활동합니다. 같은 자료의 가로축을 거리 d, 거리의 제곱 d², 거리 제곱의 역수 1/d²로 바꿔 산점도를 비교하고 **조도 I ∝ 1/d²** 관계를 확인하는 것이 목표입니다.

학생 화면의 문항 제목에는 배점·점수를 표시하지 않습니다.

학생용 GitHub Pages: **https://soomsci.github.io/ld-exp/** (로그인 없이 사용)

## 수업 운영

1. 모둠은 가설, 변인, 모둠 측정 계획을 작성합니다.
2. 모둠은 서로 다른 거리 5~6개를 확정합니다. 기본 예시는 5, 10, 15, 20, 25, 30cm이며 두 배인 거리 조건을 포함합니다. 실제 장비로 거리 범위를 사전 확인하세요.
3. 준비 단계에서 모둠원 4명의 번호·이름을 입력하고, 장비 설치를 확인한 뒤 LED를 끈 상태에서 배경 조도를 측정합니다. **0lx도 유효하며 빈칸은 미측정입니다.**
4. 모든 거리를 한 번씩 측정한 뒤 같은 거리 목록으로 2차·3차를 진행합니다. 센서가 연결되지 않는 환경에서는 수동 입력 모드로 읽은 값을 입력합니다.
5. 세 회차를 모두 마친 모둠원이 **모둠 측정 자료 제출**을 누릅니다. 다른 모둠원은 준비 단계의 **우리 모둠 자료 불러오기**를 사용합니다.
6. 모둠이 함께 제목과 가로축을 선택하고 **산점도 그리기**를 누릅니다. 세로축은 배경을 뺀 조도의 3회 평균으로 고정합니다. d → d² → 1/d²를 비교하며 축별 관찰 메모를 남길 수 있습니다. **평균점 점선 연결**을 켜면 평균점들을 가로축 값 순서로 연결합니다. 측정한 점 사이만 연결하며 원점까지 연장하지 않습니다. 이미 그린 그래프에서는 켜고 끄는 즉시 반영되고 PNG·제출 자료에도 보존됩니다. 변환값은 표와 CSV에도 포함됩니다.
7. 가장 직선에 가까운 축, 1/d² 산점도와 원점의 관계, 자신의 자료가 비례 관계를 뒷받침하는 근거를 작성하고 **실험 기록·그래프 분석 제출**을 누릅니다. 회귀선·R²·자동 정답 판정은 사용하지 않습니다. 판단하기 어렵거나 예상과 다른 자료도 그대로 답할 수 있습니다. 추가 Forms 퀴즈는 교사가 제공하는 경우에 진행합니다.

배경을 뺀 값은 음수도 그대로 표시합니다. 평균은 같은 거리의 세 회차가 모두 있어야 표시합니다. 반복이나 평균만으로 설치·거리 오차가 해결되지는 않습니다.

## 수동 입력과 센서 연결

센서 없이도 사용할 수 있습니다. 기본 입력 방식은 직접 입력입니다. 준비 화면에서 배경 조도(없으면 0)를 입력하고, 측정 화면에서 거리별 값을 기록하세요. **거리별 1·2·3차 조도 한 번에 직접 입력** 표에는 배경을 빼기 전 원래 조도를 입력한 뒤 **입력값 측정표에 적용**을 누릅니다. 0은 유효한 입력이고 빈칸은 기존 기록을 유지합니다. 모든 칸을 검사한 뒤 적용하며, 기존 값을 바꾸면 확인 후 전후 값을 이력에 보관합니다.

GitHub Pages 학생 화면에서는 센서에 직접 연결합니다. Apps Script 학생 주소는 Google의 iframe 정책 때문에 Bluetooth가 차단되므로 별도 센서 연결창(`sensor/`)으로 연결하고 값을 전달합니다. 실시간 표시는 약 1초 간격이며 측정표 저장은 **측정값 기록** 버튼으로 합니다. 공통 서비스 알림 구독 및 응답 없는 쓰기 방식을 반영했습니다.

GitHub Pages에서도 제출은 Apps Script 학생용 API를 통해 같은 Google 시트에 저장됩니다. `relay.html`은 지정한 GitHub Pages 출처의 학생용 호출 네 가지만 전달하며 교사 기능은 전달하지 않습니다. GitHub Pages 배포는 `node scripts/deploy-sensor.mjs`, Apps Script 배포는 `node scripts/deploy-school.mjs`로 관리합니다.

## 저장과 수정

- **이 기기에 임시 저장**: 브라우저 localStorage에 모둠 작성 내용과 측정 기록을 보관합니다. 서버 제출과 구분됩니다. 저장 실패 안내와 재시도 버튼을 제공합니다.
- **모둠 자료 임시 저장**: 미완료 자료도 서버에 `draft`로 저장합니다. 최종 제출로 취급하지 않으며, 다른 학생의 불러오기는 최종 제출 또는 이전 자료만 가져옵니다. 작성 중 자료를 다시 여는 기본 경로는 같은 기기의 임시 저장입니다.
- **모둠 자료 제출 완료**: 각 거리에서 3회 측정한 자료를 저장합니다. 수정하면 다시 제출해야 합니다.
- **모둠 기록 제출 완료**: 설계 답변, 그래프 구성, 축별 관찰과 분석 답변, PNG, 제출 당시 사용한 모둠 자료 사본을 함께 저장합니다. 이후 최신 모둠 자료가 바뀌어도 사본은 변하지 않습니다. 교사는 분석 답변도 함께 조회합니다.

모둠원 번호·이름은 네 명까지 기기에 임시 저장하고, 모둠 제출·불러오기, 개인 제출 당시 자료 사본, 교사 조회와 측정표 CSV에 포함합니다. 화면 위에서 반·모둠을 선택하고, 구성원 번호·이름은 네 칸에 입력합니다. 번호는 1~40의 정수이며 같은 모둠 안에서 중복할 수 없습니다. 최종 제출에서는 작성한 모둠원의 번호와 이름을 함께 입력해야 합니다. 이전 자료와 결원 모둠을 위해 빈 모둠원 칸은 허용합니다. 반·모둠을 바꾸면 구성원 칸을 비웁니다.

배경값을 다시 입력하면 이후 측정에만 적용합니다. 기존 기록을 바꾸려면 준비 단계의 **기존 기록 배경값 정정**을 명시적으로 실행하세요. 재측정·삭제·거리 제외·배경 정정의 전후 값은 이력에 남습니다. 변경 이력은 자료당 최대 150건입니다.

준비·측정 화면의 **측정 초기화**는 확인 후 측정값, 배경값, 변경 이력, 그래프 분석과 현재 제출 상태를 비우고 1차 준비부터 시작합니다. 이름·모둠원·설계 답변·거리 조건·그래프 축과 표시 설정·센서 연결은 유지합니다. 서버에 제출된 자료는 삭제하지 않습니다. 초기화 전 전체 자료는 이 기기에 한 번 백업하며 **직전 초기화 복원**으로 되돌릴 수 있습니다. 복원 시에는 측정 자료와 그래프 구성을 되돌리고 현재 이름·설계 답변은 유지합니다. 백업은 같은 계정·반·모둠에서만 복원할 수 있으며 저장 실패나 측정·제출 중에는 초기화를 진행하지 않습니다. 초기화할 자료가 없으면 기존 백업을 덮어쓰지 않습니다.

자료를 불러오거나 반·모둠을 바꿀 때 현재 측정값이 대체되면 확인하고 기기 내 별도 백업을 보관합니다. 제목·축·측정 자료가 바뀌면 그래프를 다시 그려야 제출할 수 있습니다. 분석 내용만 수정하면 그래프는 유지되며 모둠 기록을 다시 제출합니다. 이전 제출의 축 구성은 그대로 보존합니다. 이전 로컬 초안의 축 뒤바꾸기 선택은 새 활동의 거리 가로축·조도 세로축으로 전환합니다.

## 교사 화면과 배점

학생 URL 뒤에 `?page=teacher`를 붙입니다. 배포 교사와 `Code.gs`의 `TEACHERS`에 추가한 교사만 접근할 수 있습니다.

학생 상세에서 **제출 당시 자료 사본**과 **최신 모둠 자료**를 구분하여 조회합니다. 1·2·3차 값, 평균, 원래 조도, 적용 배경값, 정정 이력을 확인합니다. 제출 이력 선택으로 이전 답변·점수·그래프를 열람할 수 있으며 과거 이력은 열람 전용입니다.

그래프 채점 참고는 제목과 가로축·세로축 구성입니다. 그래프를 손으로 작도하는 능력까지 평가한 것으로 해석하지 않습니다. 기존 변인 선택의 참고 표시, 점수·피드백 저장, CSV 다운로드, 성적 시트 내보내기를 유지합니다.

**기존 20점을 재분배하지 않습니다.** 새 설치 기본값은 남는 항목의 기존 배점(가설 2, 변인 3, 계획 1, 그래프 2), 합계 8점입니다. 기존 문항 시트가 있으면 설계·그래프 항목의 사용자 설정 배점을 이어받습니다. Forms와의 합산 방식은 별도로 확정하세요. 과거 제출은 당시 문항과 만점을 적용하며 성적 CSV도 제출별 만점을 제공합니다.

## 시트와 이전 자료

| 시트 | 보관 내용 |
|---|---|
| `명렬표` | 이메일, 반, 번호, 이름, 모둠 |
| `문항` | 이전 수업 문항 보존 |
| `문항_v2` | 현재 설계·그래프 문항. 처음 실행할 때 이전 설정에서 분리 생성 |
| `모둠데이터` | 제출시각, 반·모둠, 제출자, 배경, 기록수, 버전이 있는 측정 자료 JSON |
| `제출` | 최신 개인 제출. 기존 13열 뒤에 버전·문항사본·측정사본·자료ID·제출ID 추가 |
| `제출이력` | 개인 재제출 전의 행 전체 보관 |
| `성적` | 교사가 내보낸 최신 성적표 |

명렬표가 채워져 있으면 학생 정보가 고정되고 자기 모둠 자료만 제출·불러오기 가능합니다. 명단 밖 계정은 제출할 수 없으며 교사 화면에 미제출자가 표시됩니다. 명렬표가 비어 있으면 학생이 직접 정보를 입력합니다. 모둠 칸이 비어 있으면 모둠만 직접 선택합니다.

이전 모둠의 단일 측정값은 **이전 자료·1회 측정**으로 표시하며 세 번 복제하지 않습니다. 이전 브라우저 키 `ldexp-v1`은 보존하고 새 상태는 `ldexp-v2`에 저장합니다. 과거 제출에는 당시 측정 자료 사본이 없을 수 있으며 이를 교사 화면에서 명시합니다. 재제출 전 기록과 드라이브의 기존 그래프 이미지를 삭제하지 않습니다. 문항 구성이 달라지면 이전 점수는 제출 이력에 보존하고 새 채점을 받습니다.
