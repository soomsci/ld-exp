빛의 세기와 거리 탐구

모둠 활동 준비 중…

무엇을 바꾸고 무엇을 측정할지 정해요.

탐구 질문

광원에서 멀어질수록 빛의 밝기는 어떻게 변할까?

모둠이 정한 모든 거리에서 한 번씩 측정한 뒤, 같은 거리 조건으로 2차·3차 측정을 진행해요.

장비를 연결하고 같은 측정 조건을 준비해요.

모둠원 4명

우리 모둠 구성원 4명의 번호와 이름을 적으세요. 설계부터 그래프 분석까지 함께 작성하고 모둠별로 제출해요.

센서와 입력 방식

현재 빛의 밝기 — lx

센서 연결 안 됨

센서 모드는 약 1초 동안 여러 번 읽은 평균을 한 측정값으로 기록해요. 수동 모드는 스파크뷰 등에서 읽은 값을 직접 입력해요. 1·2·3차 반복 실험은 각각 따로 진행해요.

연결 도움말센서 전원을 켜고 스파크뷰 연결을 먼저 끊으세요. 한 센서는 한 기기에만 연결돼요. 연결할 수 없는 환경에서는 수동 모드를 사용하세요.

설치 체크리스트

배경 빛의 밝기

LED를 끄고 실험 위치에서 측정해요. 0 lx도 측정값이에요.

다시 측정한 배경 빛의 밝기는 이후 기록에 적용해요. 기존 기록에는 당시 배경값이 보존돼요. 주변 조명이 달라지면 조건을 바로잡고 필요한 회차를 다시 측정하세요.

기존 기록의 배경값 정정

확인 후 모든 기존 기록에 현재 배경값을 적용하고 변경 이력을 남겨요.

모둠 공통 거리 조건

서로 다른 거리 5~6개를 정하고, 거리가 두 배인 조건을 포함해요. 기본 예시: 5, 10, 15, 20, 25, 30 cm. 실제 장비에 맞게 조정하세요.

이미 제출한 모둠 자료가 있나요?

측정 자료를 제출하면 코드가 표시돼요. 같은 모둠원에게만 알려 주세요. 이 기기에서 제출한 자료는 코드 없이 불러올 수 있어요.

측정 다시 시작

측정값·배경값·분석을 초기화하고 1차부터 다시 시작해요. 모둠원·설계 답변·거리 조건·센서 연결은 유지해요. 초기화 전 자료는 이 기기에 백업해요. 서버에 제출한 자료는 유지돼요.

같은 거리 목록을 3회 측정하고 기록을 확인해요.

거리별 1·2·3차 빛의 밝기 한 번에 직접 입력

배경을 빼기 전의 빛의 밝기(lx)를 입력하세요. 배경값은 실험 준비에서 입력하고, 결과표와 그래프에서 자동으로 빼 줘요. 빈칸은 기존 기록을 유지하며, 0도 입력할 수 있어요.

1차 측정

반복 측정의 목적반복해서 측정하면 값의 일관성을 확인하고 우연한 흔들림을 줄일 수 있어요. 설치·거리 오차는 반복이나 평균만으로 해결되지 않아요. 예상과 다르다는 이유로 기록을 삭제하지 마세요.

측정 결과 · 배경 빛의 밝기를 뺀 값

원래 측정값·배경값·변경 이력

모둠에서 한 명이 제출하고 다른 모둠원은 실험 준비에서 불러와요.

측정값·배경값·분석을 초기화하고 1차부터 다시 시작해요. 모둠원·설계 답변·거리 조건·센서 연결은 유지해요. 초기화 전 자료는 이 기기에 백업해요. 서버에 제출한 자료는 유지돼요.

같은 자료의 가로축을 바꿔 산점도를 비교하고, 빛의 밝기와 거리 제곱의 역수 사이의 비례 관계를 살펴봐요.

실험 기록과 그래프 분석 제출

제출 당시 사용한 자료, 선택한 그래프와 분석 내용이 함께 보관돼요. 수정한 뒤에는 다시 제출하세요.

추가 모둠 퀴즈는 교사가 제공하는 경우에 진행하세요.

추가 모둠 퀴즈 열기 ↗

통제변인 (같게 유지할 것)

거리 d → 거리의 제곱 d² → 거리 제곱의 역수 1/d² 순서로 바꿔 보세요. 세로축의 빛의 밝기와 측정 자료는 같아요.

가로축 값 순서로 평균점 사이만 이어 모양을 살펴봐요. 점 연결선은 측정한 점 사이의 보조 표시예요.

가로축별 메모를 따로 저장해요. 축을 바꾸면 그 축의 메모가 나타나요.

가로축 변환값과 같은 자료의 결과표

세 산점도를 비교해 분석하기

빛의 밝기 I와 1/d²의 점들이 원점 가까이를 지나는 직선에 놓인다면 I ∝ 1/d²로 볼 수 있어요. 이는 빛의 밝기가 거리의 제곱에 반비례한다는 뜻이에요. 원점은 실제 측정한 점이 아니에요. 점들의 배열을 보며 조심스럽게 판단하세요.

실제 자료가 예상과 다르면 그렇게 답해도 돼요. 직선처럼 보이는 것만으로 비례를 확정하지 말고 원점과의 관계도 살펴보세요.
